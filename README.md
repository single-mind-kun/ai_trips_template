# ai_trips_template
ai旅行攻略制作模板
请注意：
-如果只适配自己的行程，只需要使用ai旅行攻略制作模板.md就好，其余的md是我在探索的过程中，参考一些网上的资料写的，一个文件慢慢喂给ai，直到最终完成攻略的制作。
-ai旅行攻略制作模板是从这些文件里面提取出来的，由于参考的东西都是拿来即用，范围也广，因此没有附上相关作者链接。如侵权，可联系删除。
-travel-guide-planner.zip是一个skill包，可以安装到自己的ai上，也能直接使用这个仓库制作旅行攻略模板。
-仅作学习使用，不商用，还远远达不到商用的效果。
1. 先提供基础需求
至少告诉 AI：
- 出发地和返程地
- 出行日期、天数
- 人数及人员构成
- 必去景点
- 预算
- 交通、住宿和饮食偏好
- 已购买的车票、门票、住宿
- 是否需要手账图
可以直接这样告诉我：
请读取AI旅行攻略制作模板.md，为我制作旅行攻略。
出发地：深圳
目的地：桂林、阳朔
日期：2027年5月1日至5月4日
人数：4位成年人
预算：人均3500元，包含往返交通
必去：漓江、遇龙河、龙脊梯田
偏好：自然风光、摄影、当地美食，行程不要太赶
交通：优先高铁和公共交通，必要时打车
住宿：干净安静，最好靠近景区或交通枢纽
请先指出缺失的关键信息，不要立刻生成最终攻略。

2. 让 AI 先做“方案骨架”
第一轮不要直接追求完整攻略，先让 AI 输出：
- 路线顺序
- 每日主题
- 行程成立的硬前提
- 需要提前预订的项目
- 明显冲突和风险
- 需要你决定的问题
推荐指令：
先只完成模板的第1—3章，提出两套路线方案，比较时间、费用和体力强度。暂时不要制作手账图。

确定方案后，再进入详细研究，可以避免查了大量资料后又推翻路线。
3. 分专题补全信息
路线确定后，依次让 AI 补充：
1. 交通和换乘
2. 景区内部路线与门票
3. 酒店民宿
4. 美食和点单建议
5. 预算与物品清单
6. Plan B
7. 手账图提示词或实际出图
例如：
按已确认路线补充第4—7章。交通写清上下车点、末班时间和门到门耗时；酒店按具体日期和4人入住查询；餐厅每餐提供一个同片区备选。动态信息必须联网核验并标注查询日期。

4. 将已预订信息交给 AI
已经订好的内容不要让 AI 重新猜测，直接列出来：
已订信息如下：  
- 5月1日 GXXXX，深圳北至桂林北
- 5月1日晚入住某酒店
- 5月2日漓江船票，09:00场
请把这些作为不可移动节点，围绕它们调整行程；如果存在衔接风险，请明确指出。

5. 生成最终版
资料确认后使用：
请按照模板生成最终 Markdown 攻略。保留一页总览、逐日时间表、交通链、景区内部路线、美食、住宿、门票、预算、行李清单、出行贴士、Plan B、信息来源和出发前复核清单。删除未填写的占位内容。

6. 最后制作手账图
不要一开始就出图。应先确认正文中的日期、路线、班次和价格，再让 AI：
根据最终攻略的第11章，先生成无文字鸟瞰底图，再叠加中文路线。每张图只表现一天或一个景区，不得自行增加未经核验的时间、价格和地点。

三种使用深度
- 快速版： 只提供需求，让 AI 填写一页总览和逐日行程。
- 标准版： 完成交通、门票、住宿、美食、预算和 Plan B，适合普通自由行。
- 执行版： 增加景区内部路线、行李交接、末班车、触发阈值、来源核验和手账图，适合节假日、多城市或多人出行。
最推荐的是“标准版起步，重点日期升级为执行版”。这样信息足够具体，又不会让整份攻略过度冗长。
